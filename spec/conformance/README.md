# Conformance

Clawr compilers are split into a **frontend** and a **backend** that communicate through the [CIR](../cir/README.md). A frontend and a backend can be built by different teams, and a team can implement just one of them.

These pages are informative checklists, not exhaustive definitions of conformance. They contain no rules of their own: each item links to the place where the rule is defined, so there is only one definition to maintain. The keywords `MUST`, `MUST NOT` and `MAY` are used as in [RFC 2119](https://www.rfc-editor.org/info/rfc2119/).
